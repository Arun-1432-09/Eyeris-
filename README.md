# Eyeris Opticals — Interactive 3D Eyewear & Clinical Precision Platform

An interactive, high-converting 3D web platform built for **Eyeris Opticals**, located at **KPHB Road No. 1, Kukatpally, Hyderabad**. 

Carrying forward 40 years and two generations of optical mastery, Eyeris combines curated international designer eyewear (Ray-Ban, Oakley, Prada, Stepper Titanium) with hospital-grade optical precision through a direct ground-floor interconnection with **Global Eye Hospital**.

---

## Key Features

- **3D "Anatomy of Vision" Experience**: Three.js WebGL exploded-view canvas allowing visitors to interactively separate the frame into titanium temples, aspheric lenses, anti-reflective coatings, and progressive focal corridors.
- **Corporate Optical Benefit Calculator**: Customized for Hyderabad tech employees (Hitec City, Madhapur, KPHB) to calculate and claim their annual optical insurance allowances (up to ₹20,000) with zero out-of-pocket costs.
- **VIP Slot Booking & WhatsApp CRM**: Frictionless appointment scheduling that formats and dispatches booking details, preferred date/time, and intent directly to the Eyeris store WhatsApp desk with Google Maps directions.
- **Curated Brand Showcase**: Ray-Ban, Oakley (O-Matter™), Prada, Stepper Titanium, Tommy Hilfiger, and Vogue with real-time WhatsApp stock checks.
- **Eyeris Lens Lab & Reels Hub**: Vertical video hub for Instagram and YouTube short-form educational content (Doctor talks, IT screen fatigue tips, progressive lens mythbusters, and face-shape styling guides).
- **Connected Healthcare Authority**: Showcases the 3-step connected care journey directly linked on the ground floor with Global Eye Hospital.

---

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **3D Rendering**: [Three.js](https://threejs.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: CSS Transforms & Three.js Animation Loop

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
